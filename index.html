Add approval record

Every save should create a history entry. The Google Sheets backend keeps the previous status and remarks; this demo stores changes in this browser only until a Sheet is connected.

Connect Google Sheets

Publish the front-end on GitHub Pages and connect it to a Google Apps Script Web App. The spreadsheet will store current records and an append-only history log.

Setup: create a Google Sheet → Extensions → Apps Script → paste the included Code.gs → set API_KEY → run setupSheets once → Deploy as Web App (execute as you, access as anyone with the link). Keep the URL/key private to your organisation; for sensitive records, use a company-managed authenticated deployment instead.
